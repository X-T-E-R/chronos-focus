# 静流番茄专注节拍器

零依赖、纯静态的桌面端与移动端自适应专注计时单页应用，采用温润纸墨浅色界面，提供三段固定节拍（25 分钟深度专注、5 分钟短休、15 分钟长休）、任务标签绑定与 `localStorage` 本地历史留痕，所有数据仅保存在用户浏览器本地。

## 核心功能

- **三段专注节拍切换**：一键切换深度专注（25m）、短休恢复（5m）与长休整理（15m），实时更新倒计时与状态提示。
- **当前任务绑定**：支持输入正在执行的科研、编码或学习任务名称，计时结束或手动确认后自动记入今日统计。
- **本地离线统计与记录**：自动累计今日完成轮次与专注分钟数，保留最近专注记录列表，刷新页面不丢失。
- **零外部依赖**：单文件 HTML + CSS + 原生 JavaScript 实现，无需后端数据库或构建工具即可运行。

## 本地运行

```bash
npx http-server . -p 4173
```

打开 `http://127.0.0.1:4173` 即可使用。
